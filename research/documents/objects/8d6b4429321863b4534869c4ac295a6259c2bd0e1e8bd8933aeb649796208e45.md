## Design

训练与评估：V2 共同训练配方（`research/experiments/E-0008.md` 的 Design 段）与 E-0009 的正式 M 线训练程序（评估项、保存与重载规则见 E-0009 Design 段）。学习率：每个读算子用 E-0009 选出的值，同一读算子的全部 arm 相同（包括 C_dual 探针）。开始条件：E-0008 的放行门槛通过、E-0009 选出两个有限学习率、正式训练程序的代码审核通过。

| ID | 特征 | 读算子 | 融合 |
| --- | --- | --- | --- |
| V2-01 | direct_hidden | kernel_matrix | F_out |
| V2-02 | direct_hidden | kernel_matrix | C_up |
| V2-03 | direct_hidden | soft_slot | F_out |
| V2-04 | direct_hidden | soft_slot | C_up |
| V2-05 | qknorm_pre_rope | kernel_matrix | F_out |
| V2-06 | qknorm_pre_rope | kernel_matrix | C_up |
| V2-07 | qknorm_pre_rope | soft_slot | F_out |
| V2-08 | qknorm_pre_rope | soft_slot | C_up |
| V2-09 | qknorm_pre_rope | kernel_matrix | C_dual（探针） |
| V2-10 | qknorm_pre_rope | soft_slot | C_dual（探针） |

全部 arm：层 14（0-based），r128，S=1，增益 1，默认固定 softmax 缩放，出口零初始化，seed 0，4M 输入 tokens（步数相同）。每组报告 stored、trainable 与实际有梯度的参数数。

H-0003 判定（任何 V2 run 之前锁定；都用 dev 全部 1,000 条、最终 checkpoint、点估计）：
- 合格：EM_normal − max(EM_zero, EM_shuffled) ≥ 10 pp，且 NLL_normal < min(NLL_zero, NLL_shuffled)。
- 读取非退化：该 arm 在 normal memory 下对目标事实的平均地址权重 ≥ 2/16 = 0.125（均匀分布的两倍）。
- 可用正对照：E-0008 通过放行门槛（开始条件已保证）。
- supported（screening）：至少一个 arm 合格且读取非退化。challenged（screening）：没有 arm 合格。inconclusive：有 arm 合格，但它们的读取都退化；此时先用 oracle 与诊断定位。
- C_dual 探针（V2-09、V2-10）计入合格判定，但不进入下面 H-0004 的四格比较。

H-0004 判定（四格：特征 × 融合，只用 F_out 与 C_up 的 arm）：在一格中，soft_slot 同时有更高的 normal EM、更高的平均目标权重与更低的平均 n_eff，记该格 SoftmaxSlot 更好；kernel_matrix 的 normal EM 更高，记该格 KernelMatrix 更好。≥ 3/4 格 SoftmaxSlot 更好 -> supported（screening）；≥ 3/4 格 KernelMatrix 更好 -> challenged（screening）；其余 inconclusive。同时报告归一化读误差。

V3 配置选择（只在 H-0003 supported 时）：在合格且读取非退化的 arm 中，取 EM_normal − max(EM_zero, EM_shuffled) 最大者；与它相差不到 1 pp 的 arm 中，取可训练参数最少者；仍相同则取 dev NLL_normal 较低者。

描述性分析（不改变判定）：特征、读算子、融合的主效应与交互（八组析因）；C_dual 探针对同格 C_up 与 F_out 的差；每个 arm 中 normal 对 zero、shuffled 与 permuted 的 EM 差；以 episode 为单位的配对 bootstrap 95% 区间（10,000 次，seed 20261029，各 arm 与对照共用抽样索引）；key/value oracle 的结果用于定位瓶颈（value oracle 高而 normal 低 -> 寻址瓶颈；两者都低 -> 写入值或融合瓶颈）；按关系、目标事实位置与 support_order 分层；答案 ≠ 问题主语子集上的 EM；学习曲线（25/50/75% 只在 dev 上评估 normal、zero、shuffled，不用于选择）。

成本：先用 E-0009 的实测吞吐估算每组 walltime（× 1.5 申请）；十组用一个 notify 组提交。
