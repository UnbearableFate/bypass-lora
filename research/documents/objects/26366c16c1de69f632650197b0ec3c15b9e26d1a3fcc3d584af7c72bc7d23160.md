## Design

### V2 共同训练配方（E-0008、E-0009、E-0010 共用）

- 数据：E-0005 的最终数据 `/work/xg24i002/x10041/bypass-lora/runs/ATT-0039-1/data/`。作业中先核对 sha256：train `a2acb5451bc8aade1c274ebe225b4411bb3063e81bf57ba73c35101d9ac807d2`，calibration `c08753365165216b5a9f4c3d629271b2183e1323973886256867e826c1712f18`，dev `c6583cf8f7cd9d5652ed57093432b278b0600c611076fac2fe6c6b7d9e7715f4`。confirmation 不读取。
- 计数：每个 episode 的输入 tokens = `len(support_input_ids) + len(question_input_ids)`；单 token 答案只作标签，不计入。M 线与 F 线用同一计数，因此两条线在相同的 episode 与步数上训练。
- 样本顺序：依次拼接 e = 0, 1, 2 三个 epoch；每个 epoch 是 train 下标 0..16383 的排列，用 `random.Random(derive_seed(20261029, "concat_loop_v2", "V2", f"train-order-{e}")).shuffle(order)` 生成（`derive_seed` 来自 `src/v1_data.py`）。报告拼接后 episode_id 序列的 sha256。所有 V2 训练（F 线正对照、记忆校准、八组与探针）都用这个顺序。
- batch：每个优化步 8 个 episode，从上面的序列中连续取，允许跨 epoch。microbatch 可以更小，用梯度累积；loss 是这 8 个 episode 答案 CE 的平均。
- 停止：累计输入 tokens 首次达到预算的那个完整步（含该步）停止；预算在正式 run 中为 4,000,000，在学习率校准 run 中为 200,000；若先用完 3 个 epoch 则在那里停止。第一个正式 run 之前算出并报告步数与 tokens；同一实验中所有正式 run 的步数相同。
- 优化：AdamW（默认 betas 与 eps），weight decay 0，梯度裁剪 1.0；warmup 为 ceil(5% × 总步数) 步，从 0 线性升到目标学习率，之后 cosine 降到 0。可训练参数 FP32，冻结主干 BF16，eager attention，dropout 0，seed 0。
- 评估：答案位置的完整词表 EM 与答案 NLL（与 `src/v2_eval.py` 的评分相同），所有评估的 batch 固定为 16。主结果用最终 checkpoint；保存后重载，用同样的 batch 复评，预测须逐条一致。在 25%、50%、75% 步数处只在 dev 上评估，只画学习曲线，不用于任何选择。
- 学习率校准的选择规则：选 calibration 答案 NLL 最低者；NLL 或 loss 非有限的学习率记为失败；最优点落在网格端点时，向该方向扩展一次（相邻半个数量级，×3 或 ÷3），在全部候选中再选；两者 NLL 相对差小于 0.5% 时取较小的学习率。
- 先验基线：按 train 答案频率取最佳常数答案，在被评估的切片上计算 EM。
- 答案等于问题主语的 episode（生成器允许，dev 13 条，calibration 27 条）：EM 同时报告全部 episode 与“答案 ≠ 问题主语”的子集；判定用全部 episode。
- 每个 run 报告：步数、tokens、wall time、吞吐、峰值显存、MIG instance-h 与 node·h（MIG × 0.25）。

### E-0008 设计

- 模型：冻结 Base 上的 LoRA，布局与 V1-07 相同（层 [6,13,20,27]，all-7 模块，rank 10，沿用 `src/v1_lora.py`，缩放等超参与 V1-07 一致）。
- 输入：F 线提示 = `support_text + question_text`，与 `src/v2_eval.py` 的 F 线相同；只在最后一个提示位置对答案 token 计算 CE。
- 学习率校准：{1e-4, 3e-4, 1e-3} 各跑 0.2M tokens，按共同配方的规则选择。
- 正式 run：选中的学习率，4M tokens；最终 checkpoint 在 calibration 与 dev 上评估，并重载复评；报告问题主语复制率、正确答案的秩、答案 ≠ 主语子集上的 EM。
- 放行门槛（E-0010 是否开始）：calibration 完整词表 EM ≥ calibration 先验基线 + 20 pp，并且 E-0009 已为两个读算子选出有限学习率。
- 代码审核：正式 4M run 之前，对训练路径（数据顺序、计数、日程、loss 位置）与评估路径请求代码审核。校准 run 可以在测试与冒烟通过后先跑；审核要求改动训练路径时重做校准。
