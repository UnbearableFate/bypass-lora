## Design

来源：同 E-0031（顾问第 4 轮）。两位顾问对本实验意见不同。AD-0008（提案 3）认为，用户方案里的改进（X tap、写入范围、宽度）只有在主干看不到第 1 段的分段协议里，才可能改变能测到的量：同一算子在普通设置下 S1 − T0 约为 0，而在分段协议里 Keep − max(Reset, T0) 在 6 个 seed 上都为正（dev +4.4、+2.6、+1.8；A2 +3.2、+1.0、+1.9）。AD-0007 不赞成另开分段改进路线：分段证据只是提示，只应在需要时作为所选提案的诊断，不应只为再找一个正分数而运行。协调者采用 AD-0008 的理由：用户要求的是改进 H-0021（用户自己提出的 X tap）并按建议继续研究；普通设置下这些改动的效果都落在分辨率以内，只有分段协议有足够的动态范围（swap 降 4.9 至 7.0 pp）去检验它们。为回应 AD-0007 的顾虑，下面的规则只用新 seed 判定复现，并要求跨段收益本身变大，而不只是 Keep 的分数更高。

分段线的停止条件：E-0027 规则 6 与 D-0062、D-0063 规定不再对 E-0025/E-0027 的配置加 seed、加宽、换 tap 或加循环，只在新的封存契约改变侧支算子或比较方式，或用户另行要求时重开。本实验的处理：W1、W2 改变第 1 段的写入规则，是改变侧支算子的新封存契约；X 三臂是换 tap，作为用户要求下的有界例外。用户 2026-11-03 的原话是`将H-00021的关联材料发给Adviser, 获取一次改进建议, 然后整理建议进行继续研究`：H-0021 检验的正是用户提出的 X tap，AD-0008 提案 3 建议把它放到分段协议里检验。用户 2026-11-01 还表示“今后所有有意义的尝试都可以，不用请我许可”（docs/constraints.md）。本实验沿用分段协议自己的成对对照（Keep、Reset、T0），预算单列，符合用户方案 §0.1 对迁移到分段设置的两项要求；§1.3 把分段放在普通设置得到稳定收益之后，这里没有照这个顺序，理由见上。

### Arms（seed 0）

| Arm | 相对 SEG-05 的唯一改动 | 参数 |
| --- | --- | --- |
| SEG-W1 | 第 1 段只在最后一个有效 token 写入状态 | 2,752,512 |
| SEG-W2 | 第 1 段只在句末 token 与最后一个有效 token 写入 | 2,752,512 |
| SEG-X5 | tap 换成 X（input_layernorm 输出），Keep | 2,228,224 |
| SEG-X6 | 同上，Reset（段边界清空状态） | 2,228,224 |
| SEG-X7 | 同上，T0（同参数，没有历史） | 2,228,224 |

句末规则（训练前登记并冻结）：在第 1 段中，一个 token 解码后的文本去掉末尾空白后以 . ? ! 之一结尾（后面可以跟引号或右括号），并且下一个 token 以空白开头或已到第 1 段末尾，它就是句末 token；第 1 段最后一个有效 token 总是写入。报告每条样本第 1 段的写入次数（均值、最小、最大）。

W1、W2 只改第 1 段写入状态的位置，读取、第 2 段的写入与读取都与 SEG-05 相同。Reset 在段边界清空状态，T0 没有历史，它们与第 1 段的写入范围无关，所以沿用同 seed 的 SEG-06、SEG-07、SEG-04、SEG-00 记录作对照。因此对 W 变体，gain_W(s) = gain_SEG05(s) + Δ_W(s)，G 与 L 都由 Δ 推出，不是独立证据。X 三臂的初值成对相同（同 seed、同初始化规则，在 CPU 上初始化）。

参照：seed 0 来自 E-0025（BoolQ：SEG-05 65.90%，SEG-06 61.50%，SEG-07 61.20%，SEG-04 64.20%，SEG-00 60.90%，SEG-05 的 iv_swap 59.40%；gain_SEG05(0) = +4.40，但 SEG-06、SEG-07 都低于 E-0027 规则 7 的可学性线 61.90）；seed 1、2 来自 E-0027（gain +2.6、+1.8，SEG-07 学成）。这些 checkpoint 已在清理中删除，只保留预测记录；E-0030 的 SEG-05 checkpoint（seed 3 至 5）仍在 research/artifacts 下。SEG-05 的初始 adapter digest（RES-0281）：seed 0 为 f3fc8b76c81055f77e559a4df808218899b72a3716f47ea2f8e203062eb47cf5，seed 1 为 cfe01ba0cb7b2430f7cf0715d31eade2b56d2b8576ed132bc0bec2d8d959ff4e，seed 2 为 5fe32303dadc74217f587b0eaa4534af022fd0adbd8bda8b26dc3cffeaa52e33。MIG 规格：能选时，新 arm 用与同 seed 的 SEG-05 相同的规格，并记录实际规格。

### 预登记规则（运行前锁定；BoolQ dev，单位 pp；阈值含等号，按精确分数计算）

1. 实现检查（diagnostic）：新 arm 第 0 步与 iv_off 的 dev 预测等于 Base_seg；参数计数等于上表；W1、W2 的初始 adapter digest 等于同 seed SEG-05 的记录值；第 1 段写入掩码全为 true 时，输出与梯度和不带掩码的路径逐位相同；W1 每条样本第 1 段恰好写入 1 次，W2 的写入位置符合句末规则，第 2 段的写入与 SEG-05 相同；在本实验的源码上复评保留的 E-0030 SEG-05 checkpoint（seed 3，research/artifacts/ATT-0379-2，在 2g 上训练），复评在它训练时的规格上进行，分到的规格不符就在复评之前退出并重交（同 D-0073），dev 预测与记录逐条一致；X 三臂初值逐元素相同；Reset 在段边界清空状态；保存后重载预测逐条一致。不成立 -> 修实现，不下结论，也不开始正式训练。
2. 记号：对变体 V 与 seed s，Δ_V(s) = Keep_V(s) − SEG-05(s)；gain_V(s) = Keep_V(s) − max(Reset_V(s), T0_V(s))（W1、W2 用同 seed 的 SEG-06、SEG-07）；Δg_V(s) = gain_V(s) − gain_SEG05(s)。都按 BoolQ dev 精确分数计。W 变体的 Δg_V(s) = Δ_V(s)。对照学成指 max(Reset_V(s), T0_V(s)) >= SEG-00 + 1 = 61.90（E-0027 规则 7 的可学性线）。seed 0 的 SEG-06、SEG-07（61.50、61.20）都没有学成，所以 gain_SEG05(0) = +4.40 偏高；seed 1、2 的 SEG-07（63.1、63.5）学成。G_SEG05 = 88/3000（+2.933，三 seed 平均，D-0062）。
3. seed 0 筛选：W 变体 Δ_W(0) >= +1.5 -> 通过筛选（W 的 Δg 等于 Δ）。X 变体 Δ_X(0) >= +1.5 且 gain_X(0) >= G_SEG05 + 1.5（即 >= 133/3000）-> 通过筛选。seed 0 的 SEG-05 参照对照没有学成，所以 Δg_X(0) 只作描述，不进门；同时报告 Reset_X(0)、T0_X(0) 是否学成。
4. 复现：通过筛选的变体中只取 Δ_V(0) 最大的一个（相同时按 W1、W2、X 的顺序取靠前者，成本较低；三个变体的 Δ 用同一个参照，不受 seed 0 对照没学成的影响）训练 seed 1、2（W 变体每个 seed 一条 Keep，X 变体每个 seed 三条），每条 Keep 做 iv_swap。开始之前按实测重算复现成本，预测超出剩余上限时先修订契约。没有变体通过 -> 不复现。
5. supports（screening，BoolQ）：对复现的变体 V，复现只用新 seed 判定：Δ_V(1) > 0，Δ_V(2) > 0，Δg_V(1) > 0，Δg_V(2) > 0，并且 (Δg_V(1) + Δg_V(2))/2 >= +1。X 还要求 seed 1、2 上自己的对照学成；某个新 seed 上 X 的对照没有学成时，那个 seed 的 gain_X 偏高，只作描述，H-0033 不能 supports（记 inconclusive）。同时三个 seed 满足 E-0027 规则 4 的条件：G_V（gain_V 的三 seed 平均）>= +3，W_V（swap_V 的平均）>= G_V/2，L_V（Keep_V − SEG-04 的平均）>= +1。并且每个 seed 上 Keep_V 的 PIQA dev 准确率不比同 seed 的 SEG-05 低 1 pp 以上。全部满足 -> 对应假说（W1、W2 对 H-0032，X 对 H-0033）supports，并按 D-0075 的重开条件（同一协议的 dev 上出现明显更强、且能复现的侧支算子，按 BoolQ 判断）提请协调者重开分段线；新的封存确认集仍由用户决定。三个 seed 的 Δ 平均与 Δg 平均只作描述。
6. challenges 与 inconclusive：seed 0 上 Δ_V(0) <= 0 -> V 记为不支持（X 的 Δg_X(0) 不用于这条）。W1 与 W2 都不支持 -> H-0032 challenges（screening）；X 不支持 -> H-0033 challenges（screening）；复现后 (Δg_V(1) + Δg_V(2))/2 <= 0 -> 对应假说 challenges。其余情形 -> inconclusive。
7. 机制描述（不作门）：W1 与 SEG-05 相当（|Δ_W1(0)| < 1.5），与“第 1 段的状态可以只是一个摘要向量、段内 token 的寻址没有用上”相容；W2 明显高于 SEG-05，与“减少写入降低了加法干扰”相容；Δg_X > 0 与“value 内容而不是寻址限制了读取”相容。读出按 ρᵀc 归一化，W1、W2 同时改变了第 1 段写入在读出中所占的质量，所以这些都不是唯一的解释：分析报告每层第 2 段答案位置上，第 1 段写入在 ρᵀc 中所占的比例（W1、W2，以及一个保留的 E-0030 SEG-05 checkpoint）。PIQA 的同口径结果只作描述。
8. 区间与范围：配对按任务分层 bootstrap（10,000 次，seed 20261101），只描述行抽样；dev 同时用于筛选与判定；A2 不再用于确认。

### 成本、审核与记录
