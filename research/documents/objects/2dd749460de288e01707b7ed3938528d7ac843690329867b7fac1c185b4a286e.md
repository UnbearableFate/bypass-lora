**Proposal 1 — redistribute a fixed budget to attention and up outputs; first choice**

Explains: the X branch is competitive with up-only LoRA, while all-seven LoRA remains stronger with fewer parameters. A single up write may be the limiting adaptation geometry. This is an inference to test, not the established cause of the gap.

Keep four layers, the implemented normalized-X source, the current inclusive KernelMatrix S1 operator, initialization rule, eta 0.25, training order and 13,115-step budget. Compute z = eta a Ro from X **before** the layer's attention. Add three zero-initialized linear exits:

- delta_q = z C_q to q_proj output, before q_norm and RoPE;
- delta_v = z C_v to v_proj output, before GQA repetition;
- delta_up = z C_u to up_proj output, at the current C_up location.

The current layer's X determines all side Q/K/V, so there is no dependence on its modified attention output and no algebraic cycle. The backbone attention and FFN each execute once. This is different from RB1 C_dual, which writes to gate/up but leaves attention unadapted.

Use r=17 as a **budget-derived choice, not a rank search**. With D=1,024 and output widths 2,048/1,024/3,072, the derived count is

P = 4[(3D + 2048 + 1024 + 3072)r + 2r²] = **629,000**.

This is 1,784 parameters below LoRA r7 (0.28%) and substantially below X-01. Verify stored/trainable/with-gradient counts in the implementation; the arithmetic assumes the existing bias-free projections and both trainable R matrices.

**Why the other options are lower priority**

Selective feature maps, output gates, and state forgetting are different mechanisms. The X diagnostics show both diffuse and concentrated layers, so they currently lack a single identified target. An output gate overlaps with current C_up modulation by the frozen FFN gate; its existence does not guarantee selective memory use. GLA/DeltaNet and Hedgehog justify considering these operators after an interference or relevance diagnosis, not an indiscriminate replacement. The earlier SoftmaxSlot negatives were on a different M-line problem and do not rule them out here.

The r128 ordinary probe was a residual/original-tap experiment; it does not prove that wider X-C_up fails. It does reduce the expected value of another width-first screen. More layers also changes insertion coverage and must reduce per-layer rank or use a correspondingly matched LoRA, so I would first test the cheaper within-four-layer allocation above.

Longer training and calibrated or factor-specific LR remain legitimate alternatives. Eta search at fixed LR did not exhaust optimization. Nevertheless, both X and T0 improved late, and T0 caught up, so the current curves do not identify optimization as a history-specific bottleneck. I rank the identified training-objective discrepancy ahead of a broad LR/duration search. Any later optimization study must give T0 and LoRA comparable calibration and exposure budgets; it cannot compare a tuned/longer X run only to old short-run controls.
