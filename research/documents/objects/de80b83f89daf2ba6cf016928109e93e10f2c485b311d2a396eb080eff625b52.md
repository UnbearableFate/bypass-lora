## Design

依据：E-0016 的 D5 在 seed 0 上达到单独编码写入协议下的 H3（EV-0095）：EM 42.8%，对 zero 1.1%、shuffled 1.7%，差 41.1 pp，第 0 条与第 1 条及以后两个分层都过。同协议从零训练的 D4 失败（EV-0096）：读取均匀，训练 CE 停在约 4.41。D5 的配方分两段，先在 E=1 上训练（R1，ATT-0122-1），再在 E=16 上用单独编码写入续训。按 E-0016 的 outcome_actions，不用标签的配方达标后要用 seed 1、2 复现，复现后才重开 H-0003 路线。seed 0 的 R1 是现成的，所以复现必须连阶段 A 一起换成新 seed，否则只检验了续训的随机性。

### 共同配置

- 同 E-0016：V2-03 基础配置，M 线协议，冻结 Qwen3-0.6B-Base，第 14 层，direct_hidden，r128，S=1，SoftmaxSlot，F_out；LR 3e-3；每段 6000 步、每步 8 个 episode；只用最终 checkpoint；保存后重载，评估须逐例一致。
- 阶段 A（R1，seed s）：E-0014 的 R1 配方，E=1 数据（concat-loop-v2-t1-e1-1，ATT-0112-1）。初始化与数据顺序按 E-0014 中 seed 0 的同一派生规则，把 seed 换成 s。
- 阶段 B（D5）：E-0016 的 D5 配方。
  - 只加载起点的 adapter，AdamW 重置，warmup 300 步再 cosine；
  - 单独编码写入，与 E-0015、E-0016 是同一实现；E=16 数据（ATT-0039-1）；
  - 数据顺序：derive_seed(20261029, "concat_loop_v2", "V2R16", "D5", s)，s 为续训 seed。
- 代码用 master 上已审核的实现：R1 走 E-0014 的路径，D5 由 RV-0046/RV-0048、RV-0045 与 D-0017 覆盖。只换 seed 不需要新的审核；如果要改 src，先请求审核。

### Arms

| arm | 阶段 A | 阶段 B | 用途 |
| --- | --- | --- | --- |
| P1 | R1，seed 1 | D5，续训 seed 1 | 主判定 |
| P2 | R1，seed 2 | D5，续训 seed 2 | 主判定 |
| C1 | 现成的 R1 seed 0（ATT-0122-1） | D5，续训 seed 1 | 描述 |
| C2 | 现成的 R1 seed 0（ATT-0122-1） | D5，续训 seed 2 | 描述 |

C_s 与 P_s 的阶段 B 用同一个数据顺序，只差起点；C_s 与 E-0016 的 D5 只差续训顺序。

### 评估

- 阶段 B 的最终 checkpoint，在 E=16 dev（1,000）上用单独编码写入评估：
  - normal、zero、shuffled、permuted、oracle_key、oracle_value 的 EM 与 NLL；
  - 目标权重（全问题位置平均与最后位置），最后位置 n_eff；
  - 以上按目标位置分层（第 0 条，第 1 条及以后）；
  - 学习曲线（25/50/75%）。
- 阶段 A 的最终 checkpoint（P1、P2）：E=1 dev 上的 normal、zero、shuffled，只作描述，用来看阶段 A 是否学会了 value 通路。
- 描述性对照：E=16 calibration（2,048）上单独编码写入的 normal、zero、shuffled；E=16 dev 上上下文编码的 normal 与 oracle_value。

### 判定（screening）

- 每个 run 用 E-0010@2 的 H3 门槛，与 E-0016 的 D5 判定完全相同（同一个 h3_gate 实现）。在单独编码写入、标准读取协议下同时满足：
  - EM_normal − max(EM_zero, EM_shuffled) ≥ 10 pp；
  - NLL_normal < min(NLL_zero, NLL_shuffled)；
  - 全问题位置平均目标权重 ≥ 0.125；另报最后位置的权重。
- 复现判定只看 P1、P2：两个都达标为复现，只有一个达标为 inconclusive，都不达标为未复现。阶段 A 没在 E=1 学会（E=1 dev 上 EM 差 < 10 pp）时，阶段 B 照跑，如实报告。
- C1、C2 只作描述。
- 只报点估计与正确数/样本数，区间按 V2 的配对 bootstrap 只作描述。

### 实现与预算

- 两条阶段 A，四条阶段 B。P1、P2 的阶段 B 等各自阶段 A 结束后再提交；C1、C2 可以立即提交。
- 切片按 D-0018、D-0019 处理：只记录型号，不因切片失败或重跑。
- 估计：阶段 A 每条不超过约 0.1 node·h，阶段 B 每条约 0.085 node·h（D5 实测 1,221 s），合计约 0.55 node·h；上限 0.8 node·h，计入项目总额。
