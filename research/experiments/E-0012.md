## Design

依据：plan §8.3（表示层：clean-value probe 与独立 read-value probe；寻址层：目标权重、top-1、熵、n_eff）与 §8.4（全部组没有信号时，先定位失败层次，再从温度/增益校准、S=2、同布局宽度中按诊断选唯一预登记探针，最多 4M tokens；仍无信号则停止扩大新记忆路线）。本实验只测量；E-0010 的判定（H-0003 challenged，screening）不因本实验改变。结论审核 RV-0025 指出：线性探针准确率本身不能确定信息缺失或唯一原因，所以这里不设自动判定。

### 特征（冻结 Base，Qwen3-0.6B-Base，与 M 线协议一致）

- 第 14 层（0-based）。direct_hidden：该层 attention 输入的归一化 hidden，q、k、v 同源（d=1024）。qknorm_pre_rope：q 侧为 q_norm 输出（RoPE 前，16 头拼接，2048），k 侧为 k_norm 输出（RoPE 前，1024），v 侧为 v_proj 输出（1024）。
- support 与问题分别前向，与 `src/v2_memory.py` 一致：support 只含 support 文本，问题只含问题文本。特征从不带 adapter 的 Base 取。实现需用一个 E-0010 checkpoint 验证：support 与问题阶段 hook 到的投影输入与本实验提取的特征逐元素一致（容差记录在结果中）。
- 写入位置：每条事实的 `delimiter_token_index`。问题位置：(a) 头实体名字的最后一个 token（按 tokenizer offset 定位），(b) 最后一个问题 token（预测答案的位置）。

### 数据与拟合

- 拟合用 train（16,384 个 episode；按 index 最后 2,048 个留作 train 内部验证，只用于选择 L2 与训练轮数）；报告 calibration 全部 2,048 个 episode（32,768 个分隔符，2,048 个问题）的 top-1，附正确数、样本数、随机水平与常数基线。L3 沿用 `src/v2_probe.py` 的闭式 ridge，fit 用 train 的前 4,096 个 episode，held-out 用 calibration 全部；它的 split 检查保持不变。

### L0 提取与探针正对照（先于解释）

- support 中尾实体名字最后一个 token 的 v 侧特征 -> 尾实体；头实体名字最后一个 token 的 k 侧特征 -> 头实体；问题位置 (a) 的 q 侧特征 -> 头实体。每个特征集都做。任一 < 90% 时先排查位置对齐、tokenization 或探针拟合，修复后重跑，不解释 L1–L4。

### L1 冻结特征探针

- 线性探针（softmax，输入用 train 统计量标准化）：分隔符位置 v 侧 -> 尾实体（92 类）；k 侧 -> 头实体（92 类）与关系（4 类）。问题位置 (a)(b) 的 q 侧 -> 头实体与关系。
- 寻址探针：问题位置 (a)(b) 的 q 侧特征 x_q，同 episode 16 个分隔符的 k 侧特征 x_i，打分 s_i = (x_q U)·(x_i V)，秩 r ∈ {128, 256, 512, 满秩 1024}，对 16 条事实 softmax，以目标事实为标签做交叉熵，报告目标 top-1。这是有监督的寻址上界，M 线训练只有答案 CE。

### L2 训练后投影

- E-0010 十个最终 checkpoint，以及每个特征集一个随机初始化投影（与训练相同的初始化分布，seed 0）：写入的 key（读取前的正特征）、value（r=128）与问题位置的 query（Rq 与正特征之后）；线性探针 value -> 尾实体，key -> 头实体与关系，query -> 头实体与关系。

### L3 独立 clean-value 与 read-value 探针（plan §8.3）

- 十个 checkpoint 各跑一次 `src/v2_probe.py`：clean 向量为学到的目标 value，read 向量为最后一个问题位置的实际读取向量，标签为答案 token；报告 clean_to_clean、read_to_read、clean_to_read。与 L1 的冻结尾实体探针、L2 的 value 探针一起，看可解码性在写入、value 投影、读取哪一步下降；再与 E-0010 的 EM 比较融合与下游是否用上了读取信息。

### L4 读取、key 几何与融合幅度（dev 1,000 条）

- normal memory 下每个问题位置的读取 argmax 槽位：按支持顺序位置（0–15）、该事实关系是否与问题相同、是否为目标的分布；最后一个问题位置单独报告。
- episode 内 16 个写入 key 的两两余弦（均值与分位数），问题 query 对目标 key 与最高非目标 key 的分数 margin；随机初始化投影与训练后对比。
- 问题位置融合输出（F_out 的 P 增量或 C_up/C_dual 的增量）范数与第 14 层残差 hidden 范数之比（均值与分位数）。

### 之后的决定

不设自动判定。分析交付后，协调者综合 L0–L4 记录决定（rl decide，引用本实验证据）：要么预登记唯一的 §8.4 探针（E-0013，理由对应测得的层次，设计、对照与门槛在运行前锁定并审核，≤ 4M tokens），要么以预期价值有限为由停止扩大记忆路线（结论审核在先；措辞为“在这些探针下线性可解码性低”，不声称信息缺失或唯一原因）。
