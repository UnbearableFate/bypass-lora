## Design

沿用 E-0002 锁定的 release：数据切分、混合顺序、模板、截断规则、各家族学习率、batch 与优化配方。

| ID | 结构 | 可训练参数（4 层 r32，plan §15） | 学习率来源 |
| --- | --- | ---: | --- |
| V1-01 | proxy Z=SiLU(UA) + F_out | 262,144 | 加法家族 |
| V1-02 | proxy + F_pre（ZP 之后不再额外做 Norm） | 262,144 | 加法家族 |
| V1-03 | proxy + C_gate | 524,288 | concat 家族 |
| V1-04 | proxy + C_up | 524,288 | concat 家族 |
| V1-05 | proxy + C_dual | 917,504 | concat 家族 |
| V1-06 | 线性 Z=UA + C_dual（共享 A 的 gate/up LoRA 退化组） | 917,504 | concat 家族 |
| V1-07 | 同 4 层 all-7 LoRA rank10 | 901,120 | LoRA 家族 |
| V1-08 | 全 28 层 all-7 LoRA rank2 | 1,261,568 | LoRA 家族 |
| Base | 不训练，只评估 | 0 | — |

参数数以实际加载后统计为准，表中数值只是公式预期；两者不一致时先查实现。

训练：seed 0；每组上限 2M 非 padding 输入 tokens，且真实数据不超过 3 epochs；warmup 占实际优化步数的 5%，之后 cosine；所有 arm 的有效 batch 与评估频率相同。

checkpoint 规则（运行前固定）：主结果用最终 checkpoint，所有 arm 相同；在 25%、50%、75% 训练进度评估 dev，只用于画学习曲线，不用于选择。

分析：
- 主指标是 dev 上 PIQA 与 BoolQ 准确率的宏平均，同时报告各任务准确率与 NLL。
- arm 之间的差异用以样本为单位的配对 bootstrap 区间描述；这是单 seed 筛选，不作确认结论。
- 宏平均差小于 1 pp 视为“近似相同”，大致对应单 seed、每任务 1,000 条 dev 的配对噪声量级。
- F*：F_out 与 F_pre 中宏平均较高者；两者近似相同时取 F_out。
- C*：C_gate、C_up、C_dual 中有效且最简单者；与最佳者近似相同时取参数更少者。
- 额外报告：C 系列对 F 系列的差、V1-05 对 V1-06（非线性 proxy 是否有用）、C* 对 V1-07 与 V1-08（是否超出参数相近的 LoRA）。

成本：每组报告 stored、trainable 与实际有梯度的参数数，以及吞吐、wall time 和 node·h。
