## Design

训练配方：V2 共同训练配方，见 `research/experiments/E-0008.md` 的 Design 段（数据与哈希、计数、样本顺序、batch 8、停止规则、AdamW 与日程、评估 batch 16、学习率选择规则）。

正式 M 线训练程序（供 E-0009 与 E-0010 使用）：
- 复用 `src/v2_memory.py` 的 `collate`、`train_forward`、`evaluate_batch` 与对照，以及 V0 的 `BranchModel` 记忆阶段；不改 `src/bypass_*.py`、`src/v1_*.py`、`src/v2_data.py`。
- 支持的 arm：特征 direct_hidden / qknorm_pre_rope × 读算子 kernel_matrix / soft_slot × 融合 F_out / C_up / C_dual；层 14（0-based），r128，S=1，增益 1，默认固定 softmax 缩放，出口零初始化，write_scope=visible_fact_delimiter，read_scope=all_valid_question，只用答案 CE。
- 评估（最终 checkpoint，dev 与 calibration 都可选）：normal、zero、shuffled（跨 episode 打乱 support owner）、permuted（keys 不变、values 循环置换）的完整词表 EM 与答案 NLL；key oracle 与 value oracle 只作诊断；读取诊断（目标权重、top-1、margin、熵、n_eff、读误差，shuffled 只报告与目标无关的项）；按关系、目标事实位置与 support_order 分层；答案 ≠ 问题主语子集上的 EM。中间评估（25/50/75%）只在 dev 上做 normal、zero 与 shuffled。
- 保存与重载：保存全部可训练参数与配置；重载后在 dev 上复评 normal，预测须逐条一致。
- 测试：出口零初始化时 logits 与 Base 相同（三种融合 × 两个读算子 × 两种特征）；样本顺序与停止步数符合共同配方；每条事实恰好写一次；oracle 只在评估中生效；评估结果与 batch 组成无关（在 BF16 数值误差之内）；重载复评一致。

校准：代表配置 qknorm_pre_rope + F_out，读算子 kernel_matrix 与 soft_slot，学习率 {3e-4, 1e-3, 3e-3}（3e-3 是 E-0006 冒烟的默认值），各跑 0.2M tokens（共同配方的停止规则与日程），按 calibration 答案 NLL（normal memory）用共同配方的规则选择，端点时扩展一次（1e-4 或 1e-2）。同时报告 zero 与 shuffled 的 NLL 与 EM，只作诊断。

代码审核：E-0010 的正式 run 之前，正式训练程序必须通过代码审核（训练路径、对照、诊断、checkpoint I/O、C_up）。校准 run 可以在测试与冒烟通过后先跑，同时请求审核；审核要求改动训练或评估路径时重做受影响的校准。
