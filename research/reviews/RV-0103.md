## 新发现

### 1. [medium] E-0032 的 Δg 门以 seed 0 的 SEG-05 gain 为参照，而它的两个无历史对照没有学成；X 的筛选、选择与 challenges 因此偏向不利于 X
- 位置：E-0032 规则 2、3、4、6；H-0033@2。
- 证据：
  - gain_SEG05(0) = 65.90 − max(61.50, 61.20) = +4.40。SEG-06(0) 与 SEG-07(0) 只比 Base_seg（60.90）高 0.6 与 0.3 pp，都低于 E-0027 规则 7 的可学性线 SEG-00 + 1 = 61.90。E-0027 的 Design 也写了 seed 0 的这两个对照“只比 Base_seg 高 0.3 与 0.6 pp”。
  - 学成对照的 seed 1、2 上，SEG-05 的 gain 只有 +2.6 与 +1.8，T0 分别为 63.1 与 63.5（D-0062）。三 seed 的 G 为 2.933。
  - X 三臂会在 seed 0 上重新训练 Reset_X、T0_X。如果它们像 seed 1、2 那样学成（约 63），筛选要求的 Δg_X(0) ≥ +1.5 就等于 gain_X(0) ≥ 5.9、Keep_X(0) ≥ 约 68.9（比 SEG-05 高约 3 pp），而不是名义上的 +1.5。
  - 例：Keep_X(0) = 67.0（Δ_X = +1.1），max(Reset_X, T0_X) = 63.0，于是 gain_X(0) = 4.0，Δg_X(0) = −0.4。按规则 6，H-0033 记为 challenges，尽管 gain_X(0) = 4.0 高于 SEG-05 在对照学成的 seed 上的 gain（2.6、1.8）。这是把对照没学成的差异记成对 H-0033 的反驳。
  - 规则 4 在通过筛选的变体中按 Δg_V(0) 选一个复现。W 变体的 Δg_W = Δ_W 共用同一组对照，不受影响；X 的 Δg 被系统地压低约 1.5–2 pp，所以这个选择也偏向 W。
- 影响：unruled_alternative（对照没学成被当作反驳；筛选与选择有偏）。
- 修法（最小）：
  - (a) seed 0 上，参照对照没有通过 E-0027 规则 7 的可学性线时，X 的 Δg_X(0) 只作描述，不进门。X 的筛选改为 Δ_X(0) ≥ +1.5，且 gain_X(0) ≥ G_SEG05 + 1.5 = 4.433（三 seed 平均作参照），或者至少 gain_X(0) ≥ +3。
  - (b) H-0033 的 challenges 只来自 Δ_X(0) ≤ 0，或复现后新 seed 的 Δg 平均 ≤ 0；不再来自 Δg_X(0) ≤ 0。
  - (c) 规则 4 的复现选择改为比较 Δ_V(0)；或者 W 与 X 分别按自己的门判定，各自至多复现一个，并在复现前按实测重算预算。
  - (d) 报告 Reset_X(0)、T0_X(0) 是否达到 SEG-00 + 1。
  - 新 seed 上的 Δg 门不用改，seed 1、2 的参照对照已学成。
- 核对：把上例代入改后的规则：H-0033 不应记 challenges，X 的筛选按 (a) 判定；规则 2、3、4、6 的文本与 H-0033@2 的 statement 一致。

### 2. [low] E-0032 规则 1 的源码一致性复评写的是“同规格时”逐条一致；分到不同规格时，这项检查可能被跳过
- 位置：E-0032 规则 1。
- 证据：W 变体与 SEG-05 的比较依赖这项检查，因为 seed 0–2 的 SEG-05 checkpoint 已删除。D-0073 观察到：seed 4、5 的 SEG-05 在 1g 上训练，在 2g 上复评分别有 18、25 条不一致；当时的处理是设 SEG_REQUIRE_TRAINING_PROFILE=1，分到的规格不对就在复评前退出并重交。规则 1 没有规定分到不同规格时怎么办。
- 影响：nonblocking。
- 修法：写明这项复评在该 checkpoint 训练时的规格上进行，规格不符就在复评前退出并重交（同 D-0073 (1)）；检查不通过，不开始正式训练。
- 核对：规则 1 的文本；检查作业的 manifest 里记录的规格与该 checkpoint 训练时的规格相同。
