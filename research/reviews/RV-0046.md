## Finding 1 (low): `gate()` compares float EM differences, so an exact 10 pp margin can fail

- Location: `src/v2r16_isolated.py:430-431` (`margin = normal['em'] - max(zero['em'], shuffled['em'])`, `margin >= H3['em_margin']`).
- Evidence: EM values are `correct/1000` floats. With normal 300/1000 and shuffled 200/1000, `0.3 - 0.2 = 0.09999999999999998`, so `em_margin_pass` is False. `Fraction(100, 1000) >= Fraction(1, 10)` is True. Over all count pairs with a difference of exactly 100 out of 1000, 552 of 901 fail the float test. The project's other H3 gates use exact fractions over correct counts and check that the counts are aligned: `v2r_analysis.gate` (E-0014) and `v2r16_analysis.h3_gate` (T-0017, already reviewed). `v2r16_analysis` has no D4/D5 path, so this `gate()` produces the recorded H3 decision (`metrics.json` `gate`, `manifest.metrics.h3_isolated`). It is also a second implementation of a contract item that the brief says to share with T-0017.
- Impact: result_error, but only when the margin is exactly 10 pp. That is a single-count coincidence, so the conclusion is very unlikely to change.
- Fix: call the reviewed gate rather than re-implementing it:
  ```python
  from v2r16_analysis import h3_gate
  def gate(summary):
      g = h3_gate(summary, summary['normal']['diagnostics'].get('address.target_weight'))
      g['target_weight_last_position'] = summary['normal']['last_position']['target_weight_mean']
      return g
  ```
  (Alternatively compute `Fraction(normal_correct - max(zero_correct, shuffled_correct), count) >= Fraction(1, 10)` and require equal counts.) `h3_gate` raises on a None weight. If the stratified `gate_by_target_position` calls should keep their current behaviour, guard for a None weight. Update `test_isolated_gate_uses_the_e0010_h3_thresholds` to the returned keys (`em_pass`/`weight_pass`/`counts`).
- Verify: add a boundary case to the gate test (normal 300, zero 0, shuffled 200 of 1000 correct, NLL and weight passing): it must pass. 299 correct must fail. Run in the next PBS test job.
