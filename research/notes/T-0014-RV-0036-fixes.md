# T-0014 fixes for RV-0036

All three findings were accepted. These changes enforce the existing E-0013@3
contract without changing data, numerical metrics, tolerances or decision gates.
Official validation remains unopened.

1. The locked config/adapter references now must match the authenticated
   `checkpoint.json` belonging to the same final training run. The manifest
   phase, contract, validator and actual completed examples/steps are checked,
   and its recorded LR lock hash must match the lock used by confirmation.
   Synthetic regressions reject same-arm seed/path swaps, mismatched inventory
   bytes, smoke phases, incomplete budgets, wrong contracts, failed validators,
   absent final-phase metadata and different LR locks before receipt creation
   or the validation reader. The correctly bound nine-entry final grid passes.
2. `claim_unseal` is now a context manager holding one nonblocking process lock
   throughout evaluation and receipt transitions. The permanent guard inode
   is not replaced or removed. A two-process synthetic regression checks that
   the competing retry is refused while the first owns the receipt, and that
   incomplete work becomes retryable after the owner exits.
3. Receipt writes and data publication use atomic replacement of flushed files.
   A model's recovery inventory is durable before its prediction file becomes
   visible. The receipt tracks prior attempt outputs. Resume reconciles all ten
   complete bundles, recreates analysis inputs before advertising completion,
   and refuses another evaluation. Tests inject faults after the tenth
   prediction publication, during receipt replacement and before analysis-input
   publication. They check that recovery state remains valid and that recovered
   prediction artifacts can be analyzed without opening raw validation.

The numerical analysis code is unchanged from the reviewed candidate. The Base
WikiText measurement from ATT-0099-1 is reused. The previous final-candidate
regression ATT-0111-1 / RES-0102 passed 44 tests on mg1100; cumulative measured
work before these fixes is 0.00416675 node hours (0.016667 MIG instance hours,
the executor's rounded records for 37 + 23 seconds). The new targeted PBS
