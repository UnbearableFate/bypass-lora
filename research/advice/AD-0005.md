1. What the evidence supports

I inspected the supplied evidence package, constraints, the primary [RB1 analysis](/work/xg24i002/x10041/bypass-lora/runs/ATT-0267-1/analysis.md), [T-0025 delivery](/work/xg24i002/x10041/bypass-lora/research/notes/T-0025-delivery.md), [isolated-write results](/work/xg24i002/x10041/bypass-lora/research/notes/T-0018-results.md), [T2 and repair results](/work/xg24i002/x10041/bypass-lora/research/notes/T-0026-results.md), and the T0/read-summary source. I did not run models, recompute the bootstrap, or inspect sealed confirmation contents. This was read-only advisory work on login/control node miyabi-g2.

The coordinator's main RB interpretation is sound. R_res S1 is an effective trained adapter against Base, but trails matched-layout LoRA by 1.85 pp and does not beat equal-parameter T0. The frozen swap and permutation losses establish that the trained forward function depends on those inputs. They do not establish that this dependence improves the attainable trained model. The intervals describe examples conditional on one trained seed; they do not establish equivalence, seed robustness or a universal negative result.

Three refinements matter:

- The +6.95 pp macro improvement over Base is almost entirely BoolQ: +13.8 pp, versus +0.1 pp on PIQA. T0 gives +13.3/+1.0 pp. This supports a useful adaptation route but does not identify retrieval as its cause. Nor do the 2M-token curves prove a capacity ceiling: several residual arms were still improving at their final checkpoint.
- Low n_eff measures concentration, not correct addressing. The code aggregates gold-candidate answer-predicting positions: 23,183 PIQA positions versus 1,000 BoolQ positions. These are not identically weighted per-question diagnostics. A stable prefix sink, useful content retrieval and a learned bias can all yield concentrated reads. The existing summaries do not distinguish them. A sink explanation is a possibility, not an observed defect.
- [T0's implementation](/work/xg24i002/x10041/bypass-lora/src/bypass_core.py:458) is a nonlinear current-token SiLU interaction; it is not the same normalized attention operator with history simply removed. It is an appropriate trainable-capacity comparator, but the comparison is not a pure intervention on history. This motivates the same-operator reset control in the proposed experiment. Normalized attention over one current key would cancel most Q/K dependence and is not a replacement for T0.

Do not summarize the M line as “memory failed.” H-0012 establishes a useful single-hop memory path under isolated writes and R1 warm start, with screening results in three seeds. From-scratch D4 still failed, and D5's contextual-write evaluation remained poor. The multi-read extension then lost first-hop quality, failed to move reliably to successor facts, and the registered successor-supervision repair did not pass. Those results justify closing that extension; they neither erase H-0012 nor prove that no frozen-backbone memory can work.

4. Proposed experiments — choose one

Proposal 1, preferred: causal streaming memory with an explicit information boundary.

The explanation tested is that the side state has little incremental value when original attention already sees all relevant evidence, but can carry useful information once that channel is deliberately bounded. This is a new hypothesis and dataset version, not a relabeling of H-0018 or reopening of the stopped M loop.

Use the existing four-layer r32 R_res, qknorm_pre_rope, KernelMatrix and S1. Construct a small fresh single-hop binding task: eight random key/value facts, balanced values drawn from a vetted set of 16 single-token answers, distractors, and a final query. Use two/four 256-token segments. Mix two strata in training and evaluation: the queried fact is locally visible, or occurs in an earlier segment. Reset every layer's original backbone KV at each segment boundary, retaining normal attention inside each segment. Do this from the beginning of the forward path; deleting attention edges only at the final query can leave old information in intermediate hidden states.

Use counterfactual pairs with the same final query segment and different old bindings. Swap two values in the earlier facts so the answer changes while length, positions and value frequencies remain fixed. Keep both members in the same split. Use fresh mappings and balanced queried values so memorized associations, answer priors and count/position signals cannot solve the remote stratum. This is continuous contextual all-token writing, not one separately encoded fact per slot. Count every written token, not just facts.

Train four arms on identical examples and token budgets:

| Arm | Information retained across segments | Purpose |
| --- | --- | --- |
| R_keep, r32 | Side M/c only | Candidate |
| R_reset, r32 | None; reset side M/c at each boundary | Same-operator, same-parameter trained history ablation |
| T0, r32 | None | Same 663,552 effective parameters, local adaptation comparator |
| LoRA4 all7 r7 | Full ordinary context | Learnability reference with 630,784 parameters; explicitly a different information-access budget |

R_reset retains the ordinary within-segment KernelMatrix computation. T0 remains the reviewed nonlinear control. The local-visible stratum checks that both can learn the task and that resetting state did not merely destroy all competence. Keep writer gradients through carried state within each training episode; recompute state with current parameters and reset all state between episodes. Do not detach the only path from the answer loss to old writes.

Evaluate the first answer prediction using full-vocabulary exact match. Primary comparisons are R_keep minus each trained no-history control on remote cases. Use paired bootstrap over counterfactual episode pairs, not their individual rows. Retain per-distance and visible/remote results. Swap memory between counterfactual partners and score against the donor answer as well as the original answer: correct changes of answer are more informative than a generic shuffle loss. Inspect answer-position weight on the known source fact and argmax position, rather than optimizing entropy.

Proposed gates, to lock before new dev results: full-context LoRA and the trained local-visible controls reach at least 80% EM; on remote cases R_keep exceeds both R_reset and T0 by at least 10 pp, with positive lower paired interval bounds, and recovers at least half of the full-context-LoRA minus T0 accuracy gap. It should lose no more than 3 pp locally against the better local control. These are proposed pilot thresholds, not inherited evidence or a power guarantee.

Start with one seed and 2M forwarded training tokens per arm. Based on RB1, four arms cost roughly 1.0–1.2 node-h before new-path overhead; a 1–2 node-h total planning envelope is reasonable but unmeasured. Cap the entire first stage, including smoke/review checks/evaluation, at 2 node-h. A PBS smoke must measure segmented backward, evaluation and state bytes before release; if it forecasts more than the cap, the coordinator should revise or decline the proposal before running it. Do not reduce different arms to different budgets.

If the implementation or visible-task gate fails, the result is invalid/uninformative for this mechanism. If those gates pass but the remote history or gap-recovery gate fails, close the extension without another rank/tap/loop cascade. A pass warrants a small fresh-seed replication, not a large study or a second backbone. It shows successful communication through this state under the imposed boundary. A practical compression claim would additionally require an equal-total-byte memory baseline, such as an explicit bounded cache or pooled memory, and comparison of original KV plus side-state bytes and actual latency against full-context LoRA. Winning against a model denied the relevant evidence is not superiority at equal information access.

Its four-layer FP32 M+c state is analytically 66,560 bytes, excluding 32 count bytes, versus 16,896 at r32.

If either required progression condition fails, stop. A positive R64–T064 gap is screening evidence only; T0 still changes the read function, and seed variability remains unmeasured. Comparing the history gaps at r32/r64 is descriptive, not a proof that state storage specifically was limiting. Do not follow this with a feature or selectivity rescue under the same allowance.
