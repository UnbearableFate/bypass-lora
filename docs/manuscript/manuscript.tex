\begin{abstract}
本文记录 Bypass-LoRA v2 计划 V0 至 V2 的结果。研究对象是冻结的 Qwen3-0.6B-Base 旁的低维侧分支。V0 用预先锁定容差的检查验证了侧分支的实现语义（E-0001 修正后 85/85 项、E-0004 130/130 项通过）。V1 在 PIQA+BoolQ 上用不含记忆的 tokenwise proxy 比较八组接口（每组 2M tokens，seed 0）：最好的 concat 接口 C\_dual（78.15\%）只比加法 F\_out（77.80\%）高 0.35 pp，未达 1 pp 门槛；两个参数相近的 LoRA（79.20\%、79.05\%）更高。H-0002 记为 challenged（screening）。V2 研究只保留低维记忆时的单跳读取。事实在上下文中的 F 线正对照训练后通过（calibration EM 99.95\%）；按家族校准学习率后，十组 M 线配置（特征 $\times$ 读算子 $\times$ 融合的 2$\times$2$\times$2 析因，加两个 C\_dual 探针，每组 4M tokens）都没有达到运行前锁定的门槛：正常记忆对清零与打乱记忆的 EM 优势最大 +0.6 pp，门槛为 10 pp。H-0003 记为 challenged（screening）。失败定位测量显示，每组训练后在答案位置权重最高的槽位都是第一个写入的槽位，读出向量在独立探针下的答案准确率接近先验；冻结特征在写入与问题位置仍能线性解码答案，并支持有监督寻址。记忆路线按预期价值停止，计划允许的一个探针没有使用，依赖可用读取的 V3/V4 暂停。主要限制是单 seed、筛选级证据，以及失败原因的解释没有被隔离。
\end{abstract}

\section{Introduction}

Bypass-LoRA v2 在冻结主干旁加一条低维循环侧分支：从注意力的 Q/K/V 取特征，压缩成低维状态，经记忆读写与循环更新，再通过 FFN 融合写回主干。计划把研究拆成几个阶段：V0 验证实现语义（H-0001）；V1 在没有记忆与循环的 tokenwise proxy 下比较融合接口，检验把信号注入 FFN 的 gate/up 是否优于加法写回（H-0002）；从 V2 起研究丢弃 support 主干 KV、只保留低维记忆时的单跳读取（H-0003），后续还有读算子选择性（H-0004）、多次读取（H-0005）与实用适配（H-0006）。本文报告 V0、V1 与 V2 的结果，以及因 V2 没有产生可用读取而对后续阶段（V3--V5）所作的调整。各假设的陈述、范围与当前状态如下。

\section{Method}

所有实验都使用 Qwen/Qwen3-0.6B-Base（锁定 revision da87bfb6），BF16 冻结主干、FP32 新参数、eager attention，硬件为 GH200 MIG 2g.24gb；所有工作负载都在 PBS 作业中运行。E-0001 与 E-0004 是不训练的实现检查，容差在检查前由同一 Base 的重复测量锁定（BF16 atol 0.50002，FP32 2e-5），失败后不放宽。E-0002 从 PIQA 与 BoolQ 的官方 train 中切出 train、calibration 与 dev（dev 每任务 1,000 条，官方 validation 封存不读），在三个代表结构上用 0.2M tokens 比较 1e-4 与 3e-4，按 calibration NLL 选学习率，三个家族都选中 3e-4。E-0003 用 seed 0 训练八组：proxy $Z=\mathrm{SiLU}(UA)$（4 层 [6,13,20,27]，r32）分别接 F\_out、F\_pre、C\_gate、C\_up、C\_dual；线性退化组 $Z=UA$ 接 C\_dual；以及 4 层 rank10 与 28 层 rank2 的 LoRA。每组在累计 2M 非 padding 输入 tokens 的那一步停止（13,077 步，batch 2），warmup 5\% 后 cosine；主结果用最终 checkpoint，并要求重载后复评逐条一致。主指标是 dev 上 PIQA 与 BoolQ 准确率的宏平均。F*、C*、“有效”与“concat 胜出”的规则都在第一个正式 run 之前写进契约，按点估计判定；配对 bootstrap 区间（10,000 次，按任务分层）只作描述。E-0005 生成 V2 的单跳合成任务（每个 episode 16 条事实、4 种关系、单 token 答案），并在 dev 上评估 Base 的 M 线（只有问题）与 F 线（事实在上下文中）。E-0006 实现 M 线训练与诊断流水线并做冒烟。E-0007 在 calibration 切片上诊断 Base 在 F 线上失败的原因。 V2 沿用 M 线协议：support 只写不读，问题阶段丢弃 support 的主干 KV，只保留单层（index 14）、r128、S=1 的低维记忆。E-0008 先训练事实在上下文中的 F 线正对照；E-0009 按家族在 0.2M tokens 上校准学习率（KernelMatrix 1e-2，SoftmaxSlot 3e-3）。E-0010 用 seed 0 训练十组，每组 6,000 步、4,000,470 tokens，按运行前锁定的门槛判定：正常记忆的 EM 同时比清零与打乱记忆高至少 10 pp、NLL 更低、目标权重至少 0.125。它还报告 oracle 与读取诊断，以及 10,000 次配对 bootstrap 区间（只作描述）。E-0012 只做测量，不设自动判定：提取与探针正对照（L0）；冻结第 14 层特征上的线性探针与以目标事实为标签的双线性寻址探针（L1）；训练后与随机初始化投影上的探针（L2）；计划 §8.3 的独立 clean-value 与 read-value ridge 探针（L3）；读取槽位、key 几何与融合幅度（L4）。E-0011 为 V3 生成了 T2 链终点数据，因 V3 暂停而没有使用。各实验的契约摘要如下。

\subsection*{E-0001 V0 实现与不变量检查}

\begin{itemize}
\item question: 新侧分支实现能否通过 plan §6.3 的针对性检查（函数保持、两步梯度启动、冻结输入 Jacobian、同核恒等、约束融合恒等、因果、cache、reset/padding、所有权、read/write 计数、M 线信息访问、导出重载），从而可以进入训练？

\subsection*{E-0004 记忆路径就绪检查（RV-0002 跟进）}

\section{Results}

下列表格给出各实验可用 attempt 的描述性均值，不是统计检验。E-0001 与 E-0004 是 diagnostic 证据：V0 修正后 85/85 项、E-0004 130/130 项检查通过。E-0003 是单 seed 的 screening 证据：Base 的 dev 宏平均为 70.15\%，各训练组在 77.05\%--79.20\% 之间。大部分提升来自 BoolQ（Base 68.0\%，训练组 80.8\%--83.6\%）；PIQA 只从 72.3\% 升到 73.0\%--74.9\%。按预先固定的规则，F*=F\_out（77.80\%），C*=C\_up（77.70\%）。最好的 concat 组 C\_dual（78.15\%）只比 F* 高 0.35 pp（描述区间 [$-$0.60, 1.35]），记为 concat 未胜。C* 比 4 层与 28 层 LoRA 分别低 1.50 与 1.35 pp；C\_dual 对线性退化组只高 0.15 pp [$-$0.70, 1.00]。E-0005 与 E-0007 是 diagnostic 证据。Base 在 dev 上的 M 线与 F 线 EM 分别为 1.1\% 与 1.3\%，先验基线为 1.5\%。在 calibration 上，上下文事实数 E 为 1、2、4、8、16 时，F 线 EM 依次为 67.0\%、6.9\%、2.2\%、1.4\%、1.4\%；$E\geq 2$ 时，91\%--96\% 的回答是问题主语；E=16 时，在支持中的名字（去掉主语）里选对的比例为 14.2\%，随机为 3.7\%。E-0007 有一项实现检查按原规则未通过：BF16 下 batch 1 与 batch 8 的逐条 NLL 平均绝对差为 0.088，门槛为 0.05。FP32 对照把该差异降到 1e-5 量级，因此判为 BF16 数值敏感。

V2 的结果如下。E-0008 的 F 线正对照通过：事实在上下文中训练后，calibration EM 为 99.95\%（训练前 1.90\%）。E-0010 十组的 dev 正常 EM 为 0.8\%--2.1\%，清零记忆为 1.1\%，打乱记忆为 1.1\%--1.9\%；正常 EM 对两者中较大者的差最大为 +0.6 pp。所有组的平均目标权重都低于 0.125，也低于均匀的 1/16。正常与打乱记忆的 NLL 几乎相同（4.42--4.61），清零记忆为 9.25。把读取换成目标的已学 value（value oracle）后，EM 为 1.1\%--2.3\%。按锁定规则没有合格组，H-0003 记为 challenged（screening）；H-0004 的读算子比较中，两种算子都只在 0/4 格占优，记为 inconclusive。E-0012 的六项正对照为 96.6\%--100\%。在分隔符位置，冻结特征解码尾实体的准确率为 99.6\%（direct\_hidden）与 92.9\%（qknorm\_pre\_rope）。以目标事实为标签的双线性寻址探针在最后一个问题位置、秩 128--1024 下的 16 选 1 top-1 为 82.2\%--90.2\%，秩增大没有一致的提升。训练后，每组在全部 1,000 个 dev episode 的答案位置都把第一个写入的槽位排在最前。独立 ridge 探针下，读出向量的答案准确率为 1.8\%--2.3\%，已学目标 value 为 16.6\%--23.0\%。逐层 softmax 探针中，训练后 value 投影解码尾实体的准确率（17.0\%--37.1\%）不高于随机初始化投影（32.2\%--38.5\%）。融合增量与第 14 层残差范数之比的组均值为 18.7--608（V2-09 为 1.1e6）。

\section{Discussion}

证据支持以下几点。第一，V0 侧分支在所测试的恒等式与隔离项上实现正确（diagnostic，D-0003）。第二，在 V1 的固定配方下，gate/up 条件融合没有显示出超过加法写回 1 pp 的优势（screening，D-0004）。第三，V2 的单跳任务在上下文中可学（F 线正对照），但只保留低维记忆时，十组配置都没有产生可用的单跳读取（screening，D-0007）。E-0012 的测量与这样一种解释相容：训练主要通过记忆路径拟合答案先验，没有学会对目标事实寻址。这个解释没有被隔离。测量也不表明信息缺失，因为冻结特征仍能线性解码答案并支持有监督寻址。证据不支持以下推断：记忆机制普遍不可行；任何关于多次读取（H-0005）或读算子选择性（H-0004）的结论；对其他 seed、层、写入位置、事实数或损失的推断。计划 §8.4 允许的温度/增益校准（含重新训练）、S=2 与同布局宽度探针都没有测试，也没有被否定。效度方面的威胁包括：所有训练结果都是单 seed；V1 的学习率只在两个候选中校准；V2 的学习率选择主要反映先验拟合的速度；有监督寻址探针用了额外的目标事实标签；配对区间不含训练 seed 的变异。决策如下：H-0001 记为 supported；H-0002 记为 challenged 并暂停；H-0003 按预期价值停止（D-0008，结论审核 RV-0029），H-0004 记为 inconclusive，H-0005 暂停（D-0009）。按计划 §5.1 与 §14.2，V5 缩减为简单接口对比。针对所观察失败的改动（减少每个 episode 的事实数或课程式训练、单独吸收答案先验的路径、寻址监督）不在允许的探针之内，其中改变事实数需要用户决定。

\section{Conclusion}

在锁定的配置与预算内（单 seed，筛选级），V1 中 gate/up 条件融合没有优于加法写回，参数相近的 LoRA 更好；V2 中只保留低维记忆时没有产生可用的单跳读取。训练后的模型在答案位置总是把第一个写入的槽位排在最前，读出接近先验水平，而冻结特征仍含有答案信息。记忆路线按预期价值停止，V3/V4 暂停。下一步是缩减后的 V5：在 F 线、PIQA+BoolQ 上，用三个 seed 比较 V1 的 tokenwise 接口（F\_out、C\_up）与参数匹配的强 LoRA，配置与分析锁定后只开封一次官方 validation。
