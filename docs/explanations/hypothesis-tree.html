    术语表
    Base
    冻结的 Qwen3-0.6B-Base。所有方法都不改它的权重，只训练外加的小模块。
    侧支与 r
    挂在冻结主干旁边的小模块（也叫侧分支），先把特征压到 r 维（如 r32、r128）再处理，输出再接回主干。
    tap
    侧支取特征的位置。qknorm_pre_rope 取 attention 中经过 QKNorm、尚未加 RoPE 的 q 与 k，以及 v_proj 的输出；direct_hidden、X 或 N 指该层 input_layernorm 的输出。
    KernelMatrix
    正核线性注意力。把前文各位置的 kᵀv 累加成一个 r×r 的小矩阵 M，读取时用当前位置的 q 乘 M 再归一化，只看得到当前及之前的位置。
    SoftmaxSlot
    把每条事实存成一个槽位，读取时对槽位做 softmax 加权。KernelSlot 是与 KernelMatrix 等价的槽位写法，只用于恒等检查。
    T0
    同参数、无历史的对照。只用当前 token 做非线性门控 SiLU(norm(z)Rq + norm(k)) ⊙ v，不读任何前文状态；它不是去掉历史的同一种注意力。
    S1、S2、S4 与 η
    S 是侧支读取的次数。S 大于 1 时按 z ← z + η·a·Ro 累加多次读取；η 是侧支输出比例，默认 0.25。
    R_res
    块输出残差旁路，Y = B(X) + Z·P_R，把侧支输出加到原 Transformer 块的输出上。
    F_out、F_pre
    加法写回。F_out 把 ZP 加在 FFN 的输出上，F_pre 加在 FFN 的输入上。
    C_gate、C_up、C_dual
    条件融合（concat 族）。把投影后的 Z 加进冻结 FFN 的 gate 或 up 分支（C_dual 两处都加），让侧支调制 FFN 的计算。
    LoRA rN、all-7
    标准低秩适配器，rank 为 N；all-7 指 q、k、v、o、gate、up、down 七个投影都加。LoRA4、LoRA28 指加在 4 层或全部 28 层上，up-only LoRA 只加在 up_proj 上。
    冻结干预
    训练后不改权重，只改侧支状态。iv_off 关掉侧支，iv_swap 换成同任务另一样本的历史，iv_permute 打乱 key 与 value 的配对，iv_reset 在段界清空状态。
    F 线、M 线、分段协议
    F 线中主干能看到全部输入，也叫普通设置；M 线在问答时丢掉事实部分的主干 KV，只剩侧支的低维记忆；分段协议把输入拆成两段，主干在第 2 段看不到第 1 段，只有侧支状态跨段。
    单独编码写入
    每条事实不带前文、单独经过主干编码，再写进记忆；与之相对的是在完整上下文中编码。
    H3 门槛
    M 线单跳读取的锁定门槛：正常记忆的 EM 比清空记忆（zero）与打乱记忆（shuffled）中较高者至少高 10 pp，NLL 更低，目标事实的平均读权重至少 0.125。
    E、T1、T2
    E 是每个样本的事实数，如 E=16。T1 是单跳问答；T2 是沿关系链走 1 至 3 跳的链终点问答。
    oracle 对照
    评估时直接换入正确事实的 value（oracle_value）或 key（oracle_key），看下游解码本身能否答对。
    n_eff 与 sink
    n_eff 是读权重的有效项数，越小表示读取越集中。位置 0 的 sink 指读权重集中在每个样本都相同的首个 token 上。
    EM、NLL
    EM 是答案完全匹配的比例；NLL 是答案的负对数似然，越低越好。
    dev、calibration、确认集
    calibration 用来选学习率等超参数；dev 用于筛选与判定；确认集（官方 validation 或 A2）封存，只开封一次。
    diagnostic、screening、confirmatory
    证据级别。diagnostic 只说明实现或现象；screening 是单 seed、在 dev 上的筛选；confirmatory 是在封存确认集上按预登记规则做的确认。
    E0 至 E3
    实验阶段。E0 实现检查，E1 孤立机制或合成数据，E2 真实模型上的最小实验，E3 有限确认。
    pp、node·h
    pp 是百分点。node·h 是计算用量，一个节点运行一小时，MIG 切片按 1/4 计。
