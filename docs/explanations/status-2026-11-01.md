## F 线：九个正式训练在跑，判定规则训练前已锁定

这一轮是 V5（实验 E-0013）。要检验的 C_up 在第 6、13、20、27 层的 FFN 里加一个逐 token 分支：

$$\mathrm{FFN}(u) = \left[\mathrm{SiLU}(uW_g) \odot \left(uW_u + zC_u\right)\right] W_d, \qquad z = \mathrm{SiLU}(uA), \quad A \in \mathbb{R}^{1024 \times 32}$$

$u$ 是 FFN 的输入，原权重全部冻结，可训练的只有 $A$ 和 $C_u$，四层共 524,288 个参数。$C_u$ 零初始化，所以训练起点就是 Base。对手是 rank 1 的 LoRA，加在全部 28 层的 7 个线性模块上，共 630,784 个参数，比 C_up 多约 20%。次要对照 F_out 用 64 维的同类分支，乘一个矩阵后直接加到层输出，参数量和 C_up 相同。三个 arm 各用 seed 1、2、3 训练 3 个 epoch。评估用 PIQA 和 BoolQ 的官方 validation，这份数据作为确认集一直封存，九个 checkpoint 和分析脚本都锁定后只开封一次。

主判定按 seed 配对比较宏平均准确率：

$$\mathrm{Acc}_{\mathrm{macro}} = \frac{\mathrm{Acc}_{\mathrm{PIQA}} + \mathrm{Acc}_{\mathrm{BoolQ}}}{2}$$

$$\Delta_s = \mathrm{Acc}_{\mathrm{macro}}(\mathrm{C}_{\mathrm{up}}, s) - \mathrm{Acc}_{\mathrm{macro}}(\mathrm{LoRA}, s), \qquad \Delta = \frac{1}{3}\sum_{s=1}^{3} \Delta_s$$

$\delta_{\mathrm{PIQA}}$ 和 $\delta_{\mathrm{BoolQ}}$ 是三个 seed 平均后的单任务差。95% 区间来自 10,000 次配对分层 bootstrap，只重抽评估样本，反映的只是这三次训练下的数据不确定性。判定规则如下，pp 指百分点：

- supported：$\Delta \ge +1$ pp，区间下界 $> 0$，三个 $\Delta_s$ 都 $> 0$，并且 $\delta_{\mathrm{PIQA}}$、$\delta_{\mathrm{BoolQ}}$ 都 $\ge -1$ pp。这里的 +1 pp 只约束点估计，所以 supported 不等于有 95% 的把握收益至少 1 pp。
- challenged：区间上界 $< +1$ pp，结论审核后收缩主张，结束简单接口这条分支。
- 其余记 inconclusive，如实记录，不追加 seed，也不重开确认集。

能拿来参考的是 V1 筛选，它用 seed 0、每任务 1,000 条 dev 和学习率 3e-4，当时 C_up 是 77.70%，28 层 LoRA 是 79.05%，C_up 低 1.35 pp，95% 区间 $[-2.50, -0.20]$。那次的 LoRA 是 rank 2，学习率、训练量和评估集也都和这次不同，不能直接套用。但要拿到 supported，结果得明显反过来，E-0013 立项时也写明并不预期 C_up 胜出。

### 学习率都锁在 1e-3，切片问题不改锁定

calibration 是从训练数据里另切出来、不参与训练的一份，用来选超参数和做诊断。每个 arm 先用 seed 0 对每个候选学习率跑一次短训练（约 20 万个输入 token），再在 calibration 上算 NLL，即答案的负对数似然，越低越好。登记的规则是取满足 $\mathrm{NLL}(\mathrm{lr}) \le 1.01 \times \mathrm{NLL}_{\min}$ 的最小学习率，三个 arm 都选中 1e-3：

| arm | 1e-4 | 3e-4 | 1e-3 | 3e-3 |
|---|---:|---:|---:|---:|
| C_up | 1.7013 | 1.6323 | 1.5977 | 1.6025 |
| F_out | 1.6565 | 1.6022 | 1.5675 | 1.6107 |
| LoRA | 1.6645 | 1.5867 | 1.5534 | 1.6430 |

Miyabi 的 GPU 按 MIG 切成几份来用。事后核对硬件发现，12 条校准 run 里有 2 条落在较小的 1g.24gb 切片上，其中一条正好是 C 选中的 C@1e-3。两种切片上 BF16 的舍入不完全一样，结果做不到逐位一致，但这不是算错。

按你的意见，这点舍入误差不再考虑（D-0018）：锁定照用，不做敏感性比较，也不会因为作业落在哪种切片上重跑任何东西。两条在 2g 上的重跑已经跑完，只留作记录。已经接好的切片检查保留，它只用来避免跨作业逐位比对时的误报。

## M 线：答案信息还在冻结特征里，R1 学到的 value 映射一换上下文就失效

M 线只用第 14 层，宽度 $r = 128$，读一次。一个 episode 是一组事实加一个问题。读到第 $i$ 条事实末尾的分隔符时，用这个位置的冻结特征 $x_i$ 写一个槽位，key $k_i$ 和 value $v_i$ 都由 $x_i$ 投影得到，其中 $v_i = x_i A_v$。到了问题位置，query $q$ 这样读：

$$w_i = \mathrm{softmax}_i\left(\frac{q \cdot k_i}{\sqrt{r}}\right), \qquad a = \sum_i w_i v_i$$

$$\Delta h = \eta a R_o P = \eta \sum_i w_i x_i W, \qquad W = A_v R_o P$$

$\Delta h$ 加到第 14 层的输出上，$R_o$ 和 $P$ 是可训练的读出矩阵和出口矩阵，$\eta = 0.25$ 固定。从 value 到残差是一条线性路径，唯一的非线性在寻址的 softmax。

可用门槛 H3 要三条同时成立。EM 是完全答对的比例，zero 是把记忆清空，shuffled 是换成另一个 episode 的记忆：

- $\mathrm{EM}_{\mathrm{normal}} - \max(\mathrm{EM}_{\mathrm{zero}}, \mathrm{EM}_{\mathrm{shuffled}}) \ge 10$ pp
- $\mathrm{NLL}_{\mathrm{normal}} < \min(\mathrm{NLL}_{\mathrm{zero}}, \mathrm{NLL}_{\mathrm{shuffled}})$
- 目标事实的平均地址权重 $\ge 0.125$，即 16 个槽位均匀分配时的两倍

V2 的十组配置都没过，H-0003 记为 challenged，记忆路线一度停掉（D-0008）。你后来允许重开，也允许改数据协议。E-0014 在 V2 的一组配置 V2-03 上一次只改一处，共六组：每个 episode 只放 1 条或 4 条事实、事实数课程、先训练一条吸收答案先验的通路、给地址权重加监督、去中心化余弦寻址。记每个 episode 的事实数为 E，E=16 上六组都没过 H3。只用 1 条事实训练的 R1 在 E=1 上 EM 比对照高 82.6 pp，写、读、解码这条通路能学会，但同一个 checkpoint 拿到 E=16 上反而比对照低 0.7 pp。

E-0015 不训练，只在 calibration 上诊断 R1、R2、R5 和 V2-03 的 checkpoint。EM（%）如下，前四行是正常读取：

| checkpoint | E=1 | E=4 | E=16 |
|---|---:|---:|---:|
| R1（E=1 训练） | 84.1 | 1.1 | 0.5 |
| R2（E=4 训练） | 11.9 | 9.7 | 2.8 |
| R5（E=16，加地址监督） | 6.1 | 7.6 | 6.4 |
| V2-03（V2 原配方） | 1.6 | 1.7 | 1.5 |
| R1 直接读正确事实的 value | 84.1 | 21.9 | 7.6 |

V2-03 各列都在随机水平。R1 直接读正确事实的 value 时，E=16 上按目标事实的位置拆开，第 0 条是 83.4%，第 1 条及以后只有 1.6%。如果每条事实先单独编码再写入，同样直接读正确的 value，第 0 条 83.4%，第 1 条及以后 86.7%。换成错误事实的单独编码 value 只有 1.5%，和答案先验（总猜最常见的答案）的 1.9% 相当。

答案信息还在冻结特征里，线性探针在 E=16 上能以 94.9% 的准确率把答案解出来。出问题的是 R1 学到的 value：单独编码时各位置的 L2 范数都约 44，放进上下文后第 1 到 3 条变成 103.1，第 4 条起约 89，冻结特征则一直在 57 左右。R1 学到的映射只适合前面没有别的事实的写法，我们把这叫作上下文迁移。

这轮诊断预先写了 8 条规则，2、4、5 成立，其余不成立。第 4、5 条对应上面的数字：前者看 R1 直接读正确 value 时，E=4、16 是否比 E=1 低 30 pp 以上，后者看单独编码后第 0 条和后面各条是否都过 70%。第 2 条看的是训练出的 value 上探针低于 50%、冻结特征上高于 90%，它在随机水平的 V2-03 上也成立，分不开好坏 checkpoint。规则 3 和 7 排除了两个解释：只在最后一个问题位置读取并不涨分，可见非末位位置的混合读取没有干扰解码；把增量乘以 $\alpha < 1$ 后 EM 全都下降，增量过大也不是原因。

### 下一轮分开训练解码和寻址，并试单独编码写入

E-0016 沿用 V2-03 的配置和 E=16，单 seed，每段 6000 步。D1 训练时记忆里只留目标槽位，等于告诉模型正确事实在哪（额外监督），先把 value 到答案的解码学会，门槛是 EM 比对照高 50 pp。D2a、D2b 从 D1 接着训，恢复全部槽位，只靠答案的交叉熵学寻址，D2a 只训寻址参数，D2b 全部参数都训。D3 只在最后一个问题位置读取，把读哪个槽位当作隐变量，训练目标改成

$$L = -\log \sum_i w_i \cdot p\left(\text{answer} \mid \text{only } v_i\right)$$

原来的做法是先把 value 按权重混成一个向量再解码，D3 改成每个槽位单独解码，再按权重把答案概率加起来，不用目标索引。D4、D5 把每条事实单独编码后写入，D4 从零训，D5 从 R1 接着训。D2 到 D5 都用 H3 判定，D3 改用只读最后位置、取权重最大槽位的读法来算。

去向也事先定好了。D3、D4、D5 都不用标签，任何一个过门槛，就用 seed 1、2 复现，复现后按这个配方重开记忆路线。如果 D1 的差值不到 20 pp 且训练损失已经不降，D4、D5 也没过，就暂停 M 线，V5 不受影响。

D1、D2a、D2b、D3 已由 researcher-1 实现。两轮冒烟都通过了：新选项关闭时输出与原代码逐位一致，保存后重载的结果一致，D3 每步耗时和原配置差不多（0.95 倍），远低于 3 倍的停止线。代码审核（RV-0045）正在进行，通过后才跑 6000 步的正式 run。D4、D5 以上面的规则 5 成立为前提，现在成立了，已建成任务 T-0018 交给 researcher-3。它在实现单独编码写入的训练路径，评估和续训直接复用 researcher-1 的代码。
